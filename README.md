# Kanchanaburi Wildfire & Durian Spatial Analytics
> **ระบบ Interactive Dashboard สำหรับสำรวจและเปรียบเทียบข้อมูลจุดความร้อนในพื้นที่ป่าอนุรักษ์ กับข้อมูลพื้นที่เพาะปลูกทุเรียน จ.กาญจนบุรี**
> *เวอร์ชันสมบูรณ์ระดับมืออาชีพ (Professional Executive Dark Dashboard)*

พัฒนาด้วย **Python**, **Streamlit** และ **Plotly** ตามข้อกำหนดเชิงลึกในเอกสาร `BRD.md`, แบบจำลองข้อมูลใน `Data_Dictionary.md`, แนวทางการส่งมอบใน `HanDoff.md` และภาพร่าง Wireframe Layout

---

## 📌 จุดเด่นของการออกแบบระดับ Executive (UI/UX Highlights)
1. **Dark & Fire Theme (ธีมดำ-แดงไฟป่า):**  
   บังคับใช้ Dark Mode ทั่วทั้งระบบ โดยใช้พื้นหลังสีดำถ่านลึก (`#0E1117`), การ์ดคอนเทนเนอร์ (`#161B22`) และชุดสีกราฟโทนความร้อนและไฟป่า (Crimson Red `#E53935`, Flame Orange `#FF7043`, Amber Gold `#FFA726`) พร้อมแผนที่ดาวเทียมสไตล์ `carto-darkmatter`
2. **Clean & Minimalist Design:**  
   ปราศจาก Emoji ทั้งหมดในชื่อระบบ แท็บ หัวข้อ ตัวชี้วัด และปุ่มกด เพื่อความเป็นทางการและน่าเชื่อถือ ตัดข้อความอธิบายที่เยิ่นเย้อออกทั้งหมด ให้เหลือเฉพาะข้อมูลเชิงสถิติที่จำเป็น
3. **No Text Truncation Guarantee:**  
   ใช้ Custom CSS บังคับให้ข้อความในกล่อง Metrics ตัดขึ้นบรรทัดใหม่ได้แบบ 100% ปราศจากปัญหาตัวอักษรโดนตัดหรือแสดงเป็นจุดไข่ปลา `...`
4. **Clean Plotly Presentation:**  
   ซ่อนแถบเครื่องมือ Modebar ที่ไม่จำเป็นของ Plotly เพื่อความสะอาดตาในการนำเสนอผลงาน
5. **Data Integrity & Academic Rigor:**  
   ยอดรวมจุดความร้อนคงที่ **8,606 จุด** เสมอ ไม่มีการนับซ้ำจากการ Join พร้อมระบบตรวจสอบสถิติ Mann-Whitney U Test และข้อความปฏิเสธข้อสรุปเชิงสาเหตุ (No Causal Inference) อย่างเคร่งครัด

## 🚀 ฟังก์ชันการทำงานของ Dashboard (3 แท็บหลัก)

### 1. ภาพรวมจุดความร้อน (Hotspots Overview)
- **ตัวชี้วัดสำคัญและมาตรวัด Gauge:** แสดงยอดจุดความร้อนในตัวกรอง สัดส่วนเทียบทั้งจังหวัด อำเภอที่พบจุดสูงสุด และสถานีควบคุมไฟป่าที่มีภาระงานสูงสุด
- **แผนที่พิกัด (Carto-Darkmatter Map):** แสดงจุดพิกัดจริง (LAT, LONG) บนแผนที่โทนดำ พร้อมชั้นสีจำแนกตามประเภทป่าอนุรักษ์
- **แนวโน้มเชิงเวลา (Temporal Wave & Hourly Breakdown):** 
  - กราฟคลื่นฤดูกาลรายเดือน (Seasonal Wave)
  - การกระจายตัวรายชั่วโมง (0-23 น.) ตามรอบวงโคจรดาวเทียม
- **ภาระงานสถานีควบคุมไฟป่า (Station Workload):** แผนภูมิแท่งแนวนอนและตารางแจกแจงระดับความเชื่อมั่น (CONFEDENCE Matrix)

### 2. พื้นที่ปลูกทุเรียน (Durian Cultivation)
- **แนวโน้มประวัติศาสตร์ (พ.ศ. 2561 - 2568):** แผนภูมิแท่งและเส้นแนวโน้มการเติบโตของพื้นที่ปลูกทุเรียนรวมทั้งจังหวัด (หน่วย: ไร่)
- **การจัดอันดับรายพื้นที่:** แผนภูมิแท่งจัดอันดับรายอำเภอ และตารางแสดงข้อมูลรายตำบล
- **แยกสถานะข้อมูลชัดเจน:**
  - `0.0 ไร่`: สำรวจแล้ว มีรายงานว่าไม่มีการปลูก
  - `ไม่มีข้อมูลสำรวจ (Null)`: ตำบลที่ไม่มีข้อมูลการสำรวจในรอบปีนั้น

### 3. การเปรียบเทียบเชิงพื้นที่และสถิติ (Spatial & Statistical Comparison)
- **Dual-Axis Comparison Chart:** เปรียบเทียบปีต่อปี (พ.ศ. 2566 - 2568) ระหว่างพื้นที่เพาะปลูกทุเรียน (แกนซ้าย) และจำนวนจุดความร้อน (แกนขวา)
- **Bubble Chart:** ความสัมพันธ์ระดับตำบลระหว่างพื้นที่ปลูกทุเรียน (แกน X) กับจำนวนจุดความร้อน (แกน Y)
- **การทดสอบนัยสำคัญทางสถิติ Mann-Whitney U Test:**
  - เปรียบเทียบค่ากลางของ `hotspot_count` ระหว่างกลุ่มตำบลที่ปลูกทุเรียน (`Area > 0`) กับกลุ่มที่ไม่ปลูก (`Area == 0`)
  - แสดงค่าขนาดกลุ่มตัวอย่าง (Sample Size $N_1, N_2$), ค่าเฉลี่ย/มัธยฐาน, ค่าสถิติ $U$, ค่า $p$-value และขนาดอิทธิพล (Effect Size: Rank-Biserial Correlation $r$)
- **ตารางเปรียบเทียบระดับตำบลอย่างละเอียด:** แสดงข้อมูลคู่ขนานรายปีในรูปแบบเรียบหรู
