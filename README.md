# Kanchanaburi Wildfire & Durian Interactive Dashboard
> **ระบบ Interactive Dashboard สำหรับสำรวจและเปรียบเทียบข้อมูลจุดความร้อนในพื้นที่ป่าอนุรักษ์ กับข้อมูลพื้นที่เพาะปลูกทุเรียน จ.กาญจนบุรี**

พัฒนาด้วย **Python**, **Streamlit** และ **Plotly** ตามข้อกำหนดเชิงลึกในเอกสาร `BRD.md`, แบบจำลองข้อมูลใน `Data_Dictionary.md`, แนวทางการส่งมอบใน `HanDoff.md` และภาพร่าง Wireframe Layout

---

## 📌 วัตถุประสงค์ (Business Objective)
มุ่งเน้นการแสดงข้อเท็จจริงเชิงพื้นที่ (Spatial) และเชิงเวลา (Temporal) อย่างโปร่งใส ถูกต้อง และเป็นกลาง โดย **ปราศจากการสร้างข้อสรุปเชิงสาเหตุ (No Causal Inference)** ว่าการปลูกทุเรียนเป็นสาเหตุของไฟป่า

## 🚀 ฟังก์ชันการทำงานของ Dashboard (3 แท็บหลัก)

### 🔥 Tab 1: ภาพรวมจุดความร้อน (Hotspots Overview)
- **มาตรวัด Gauge และ KPIs:** แสดงยอดจุดความร้อนในตัวกรอง สัดส่วนเทียบทั้งจังหวัด อำเภอที่พบจุดสูงสุด และสถานีควบคุมไฟป่าที่มีภาระงานสูงสุด
- **แผนที่พิกัดจุดความร้อน (Interactive Map):** แสดงจุดพิกัดจริง (LAT, LONG) บนแผนที่ พร้อมชั้นสีจำแนกตามประเภทป่าอนุรักษ์ และ Tooltip รายละเอียดเวลา/ระดับความน่าเชื่อถือ
- **การวิเคราะห์เชิงเวลา (Temporal Wave & Hourly):** 
  - ฤดูกาลรายเดือน (Seasonal Wave) เปรียบเทียบปี พ.ศ. 2566, 2567, 2568
  - การกระจายตัวรายชั่วโมง (0-23 น.) ตามรอบวงโคจรดาวเทียม (Spikes ชัดเจนช่วงตี 1-2 และ บ่าย 1-2)
- **ภาระงานรายสถานี (Station Workload - RQ8):** แผนภูมิแท่งแนวนอนและตารางแจกแจงระดับความเชื่อมั่น (CONFEDENCE)

### 🍈 Tab 2: พื้นที่ปลูกทุเรียน (Durian Cultivation)
- **แนวโน้มประวัติศาสตร์ (พ.ศ. 2561 - 2568 - RQ5):** แผนภูมิแท่งและเส้นแนวโน้มการเติบโตของพื้นที่ปลูกทุเรียนรวมทั้งจังหวัด (หน่วย: ไร่)
- **การจัดอันดับรายพื้นที่ (RQ2):** แผนภูมิแท่งจัดอันดับรายอำเภอ และตารางแสดงข้อมูลรายตำบล
- **Zero vs Missing Highlighting:** มีการจัดรูปแบบแยกสถานะชัดเจนระหว่าง:
  - `0.0 ไร่`: สำรวจแล้ว มีรายงานว่าไม่มีการปลูก
  - `ไม่มีข้อมูลสำรวจ (Null)`: ตำบลที่ไม่มีข้อมูลการสำรวจในรอบปีนั้น

### ⚖️ Tab 3: การเปรียบเทียบเชิงพื้นที่และสถิติ (Spatial & Statistical Comparison)
- **Dual-Axis Comparison Chart:** เปรียบเทียบปีต่อปี (พ.ศ. 2566 - 2568) ระหว่างพื้นที่เพาะปลูกทุเรียน (แกนซ้าย) และจำนวนจุดความร้อน (แกนขวา)
- **Bubble Chart:** ความสัมพันธ์ระดับตำบลระหว่างพื้นที่ปลูกทุเรียน (แกน X) กับจำนวนจุดความร้อน (แกน Y) โดยขนาดของฟองสบู่สะท้อนปริมาณจุดความร้อน
- **การทดสอบนัยสำคัญทางสถิติ Mann-Whitney U Test:**
  - เปรียบเทียบค่ากลางของ `hotspot_count` ระหว่างกลุ่มตำบลที่ปลูกทุเรียน (`Area > 0`) กับกลุ่มที่ไม่ปลูก (`Area == 0`)
  - แสดงค่าขนาดกลุ่มตัวอย่าง (Sample Size $N_1, N_2$), ค่าเฉลี่ย/มัธยฐาน, ค่าสถิติ $U$, ค่า $p$-value และขนาดอิทธิพล (Effect Size: Rank-Biserial Correlation $r$)
- **ตารางเปรียบเทียบระดับตำบลอย่างละเอียด:** แสดงข้อมูลคู่ขนานรายปี พร้อม Heatmap การกระจุกตัว

## 🛠️ วิธีการติดตั้งและเริ่มใช้งาน (Installation & Setup)

1. **โคลนโปรเจกต์หรือเข้าสู่ไดเรกทอรีโปรเจกต์:**
   ```bash
   cd c:\Users\Administrator\Downloads\Dashboard_Project
   ```

2. **ติดตั้งไลบรารีที่จำเป็น:**
   ```bash
   pip install -r requirements.txt
   ```

3. **รันแอปพลิเคชัน Streamlit:**
   ```bash
   streamlit run app.py
   ```

4. **เปิดใช้งานบนเว็บเบราว์เซอร์:**
   โดยปกติ Streamlit จะเปิดเบราว์เซอร์ให้อัตโนมัติที่ `http://localhost:8501`
