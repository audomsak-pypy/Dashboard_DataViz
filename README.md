# ระบบวิเคราะห์ข้อมูลจุดความร้อนในพื้นที่ป่าอนุรักษ์และพื้นที่เพาะปลูกทุเรียน จังหวัดกาญจนบุรี
## (Kanchanaburi Wildfire & Durian Spatial Analytics)

ระบบ **Interactive Executive Dashboard** สำหรับการสำรวจ วิเคราะห์ และเปรียบเทียบข้อมูลจุดความร้อน (Hotspots) ในพื้นที่ป่าอนุรักษ์ กับข้อมูลพื้นที่เพาะปลูกทุเรียนในจังหวัดกาญจนบุรี ในมิติเชิงพื้นที่ (Spatial) และเชิงเวลา (Temporal) โดยมุ่งเน้นการนำเสนอข้อมูลจริงอย่างเป็นกลางและโปร่งใส เพื่อใช้เป็นเครื่องมือสนับสนุนการวางแผนเชิงพื้นที่และการบริหารจัดการทรัพยากรธรรมชาติ

---

## เทคโนโลยีที่ใช้งาน (Tech Stack)

- **ภาษาหลัก:** Python 3.11+
- **เว็บเฟรมเวิร์ก:** [Streamlit](https://streamlit.io/) (เวอร์ชัน 1.30+)
- **การสร้างแผนภูมิและการแสดงผลข้อมูล (Data Visualization):** [Plotly](https://plotly.com/python/) (เวอร์ชัน 7.x พร้อม MapLibre GL)
- **การจัดการและประมวลผลข้อมูล (Data Processing):** [Pandas](https://pandas.pydata.org/) และ [NumPy](https://numpy.org/)
- **การวิเคราะห์ทางสถิติ (Statistical Testing):** [SciPy](https://scipy.org/) (Mann-Whitney U Test)
- **ระบบแผนที่ฐาน (Basemap):** Carto Darkmatter (WGS84 Geographic Coordinates)

## จุดเด่นและฟังก์ชันการทำงานหลัก (Key Features)

แดชบอร์ดถูกออกแบบภายใต้แนวคิด **Visual-First & Professional Dark Theme** โดยแบ่งการวิเคราะห์ออกเป็น 3 ส่วนหลัก:

### 1. ภาพรวมจุดความร้อน (Hotspots Overview)
- **ตัวชี้วัดสำคัญ (Key Metrics & Gauges):** มาตรวัดแสดงจำนวนจุดความร้อนในตัวกรอง สัดส่วนเทียบทั้งจังหวัด อำเภอที่พบจุดสูงสุด และสถานีควบคุมไฟป่าที่มีภาระงานสูงสุด
- **แผนที่พิกัดดาวเทียม (Interactive Map):** รองรับทั้งรูปแบบ **จุดพิกัด (Scatter Map)** และ **แผนที่ความหนาแน่น (Density Heatmap)** บนพื้นหลังธีมมืด (Carto Darkmatter)
- **การวิเคราะห์เชิงเวลา (Temporal Trends):**
  - กราฟคลื่นฤดูกาลรายเดือน (Seasonal Wave) แสดงแนวโน้มการเกิดไฟป่าเปรียบเทียบรายปี
  - กราฟแจกแจงรายชั่วโมง (Hourly Breakdown) ตามรอบการโคจรผ่านของดาวเทียมตรวจจับ
- **การจัดสรรภาระงาน (Station Workload):** แสดงปริมาณจุดความร้อนในความรับผิดชอบของแต่ละสถานีควบคุมไฟป่า พร้อมตารางแจกแจงระดับความเชื่อมั่น (Confidence Matrix)

### 2. ข้อมูลพื้นที่เพาะปลูกทุเรียน (Durian Cultivation)
- **แนวโน้มรายปี (พ.ศ. 2561 - 2568):** แสดงการเปลี่ยนแปลงและอัตราการเติบโตของพื้นที่เพาะปลูกทุเรียนรวมทั้งจังหวัด
- **การจัดอันดับพื้นที่รายอำเภอและตำบล:** ตารางและกราฟแท่งจัดอันดับพื้นที่เพาะปลูก (หน่วย: ไร่)
- **ความแม่นยำของสถานะข้อมูล:** แยกความแตกต่างอย่างชัดเจนระหว่างพื้นที่ที่ **สำรวจแล้วไม่พบการเพาะปลูก (0.0 ไร่)** กับพื้นที่ที่ **ไม่มีข้อมูลการสำรวจ (Null)**

### 3. การเปรียบเทียบเชิงพื้นที่และสถิติ (Spatial & Statistical Comparison)
- **กราฟเปรียบเทียบสองแกน (Dual-Axis Chart):** เปรียบเทียบข้อมูลคู่ขนานรายปี (พ.ศ. 2566 - 2568) ระหว่างพื้นที่ปลูกทุเรียนกับจำนวนจุดความร้อน
- **แผนภูมิฟองสบู่ (Bubble Chart):** แสดงการกระจายตัวและความสัมพันธ์ระดับตำบล
- **การทดสอบนัยสำคัญทางสถิติ (Mann-Whitney U Test):** ทดสอบความแตกต่างของค่ากลางจุดความร้อนระหว่างกลุ่มตำบลที่มีการปลูกทุเรียนกับกลุ่มที่ไม่มีการปลูก พร้อมรายงานค่าสถิติ $U$, $p$-value, และ Effect Size ($r$)

##  วิธีการติดตั้งและรันโปรเจกต์บนเครื่องคอมพิวเตอร์ (Local Setup)

### ขั้นตอนที่ 1: เตรียมสภาพแวดล้อม Python
ตรวจสอบให้แน่ใจว่าได้ติดตั้ง Python เวอร์ชัน 3.11 ขึ้นไป:
```bash
python --version
```

### ขั้นตอนที่ 2: ติดตั้งไลบรารีที่จำเป็น (Dependencies)
เปิด Terminal หรือ Command Prompt ในโฟลเดอร์โปรเจกต์ แล้วรันคำสั่ง:
```bash
pip install -r requirements.txt
```
*(ไลบรารีหลักประกอบด้วย `streamlit`, `plotly`, `pandas`, `numpy`, และ `scipy`)*

### ขั้นตอนที่ 3: เริ่มต้นรันแดชบอร์ด
รันคำสั่งเพื่อเปิดใช้งานแอปพลิเคชัน Streamlit:
```bash
streamlit run app.py
```

### ขั้นตอนที่ 4: เปิดใช้งานบนเว็บเบราว์เซอร์
เมื่อคำสั่งเริ่มทำงานสำเร็จ ระบบจะเปิดหน้าเว็บเบราว์เซอร์ให้อัตโนมัติ หรือสามารถเข้าผ่าน URL ต่อไปนี้:
```
http://localhost:8501
```

## ข้อกำหนดด้านความถูกต้องและข้อจำกัดของข้อมูล (Data Governance)
- **ยอดรวมจุดความร้อนคงที่ (Data Integrity):** ยอดรวมจุดความร้อนในแดชบอร์ดคงที่ที่ **8,606 จุด** เสมอ ไม่มีการนับซ้ำจากการประมวลผลและการเชื่อมโยงข้อมูล (Outer Join)
- **ข้อจำกัดเชิงวิชาการ (No Causal Inference):** การเปรียบเทียบใช้ขอบเขตการปกครองระดับตำบลเป็นเกณฑ์ ไม่ได้หมายความว่าจุดความร้อนเกิดขึ้นในหรือติดกับแปลงเพาะปลูกทุเรียน และข้อมูลไม่สามารถสรุปความเป็นเหตุเป็นผลได้ เนื่องจากไม่มีข้อมูลพิกัดแปลงเพาะปลูกจริง
